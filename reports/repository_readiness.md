# Public repository and evidence layout

The project is published at [DB825/adverse-selection-rl-market-makers](https://github.com/DB825/adverse-selection-rl-market-makers) under the [MIT license](../LICENSE). It contains the simulator, inference and training code, tests, configurations, scientific reports and two frozen public snapshots of text evidence.

`results/` holds original machine-local run records and is excluded from Git. `published-results/` holds public JSON, CSV and test XML copies. Local machine paths were sanitized without changing numerical results. The [publication manifest](../published-results/publication_manifest.json) records each file's original and public SHA-256 hashes. The [iteration manifest](../published-results/iteration-v1/publication_manifest.json) adds independent-seed replication and nonlinear-history controls without modifying the first snapshot. Together the manifests verify 782 files. Original files remain intact locally. Historical experiment manifests retain their original checksums; they are provenance records, not assertions that sanitized copies or excluded binaries have identical bytes. Verify public bytes with `python -m scripts.verify_publication`.

Checkpoints, activation/prediction arrays, TensorBoard logs, the virtual environment, superseded overlapping-seed runs and local inventory/delivery records are excluded. The snapshot includes supporting smoke and benchmark records; only the cohorts and runs identified in the memos contribute substantive findings. Published text supports inspection of seed outcomes, episode-level economic results and probe summaries. Full training and representation audits require regenerating the excluded binaries.

Historical runs used Windows, Python 3.13.7 and CPU PyTorch 2.8.0. The full lock records that environment. CI independently installs direct pinned dependencies, runs the tests, verifies the evidence snapshot, and exercises a short train/evaluate cycle on Windows and Linux. Its live status is available in [GitHub Actions](https://github.com/DB825/adverse-selection-rl-market-makers/actions). Passing CI establishes executable functionality on those runners; it does not establish identical stochastic trajectories or convergence.

The source snapshot is reusable as a research and portfolio project. The defensible claim is controlled study of recurrent learning, decoder controls and verified experiment execution. Reliable recurrent learning, a recurrence advantage, information uniquely attributable to older memory and causal use of adverse-selection representations remain unestablished. See the [replication memo](replication_memo.md), [nonlinear-control memo](nonlinear_memo.md) and [managed execution contract](managed_execution.md) and [next experiments](next_experiments.md).
