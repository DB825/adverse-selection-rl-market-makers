# Fresh-cohort nonlinear recent-history control

Fixed before collecting the new cohort or fitting its decoders, 27 September 2026.

Freeze the five existing entropy-.01 recurrent checkpoints, seeds 11–15, at their archived SHA-256 hashes. Include both economically weak seeds. Collect **1,024 episodes beginning at 14,000,000**, separate from all prior economic/probe cohorts and from the independent-seed replication. Use the same stochastic evaluation, targets, fixed reference quote and predecision timing. This evaluates the original development policies, not the new replication policies.

Use arrivals 8–63 and the existing split seed 73: 614 whole training episodes, 205 validation episodes and 205 test episodes. Refit all existing ridge panels on this fresh cohort: basic observables, history8, trained state, basic plus trained state, history plus trained state, untrained state and history plus untrained state. Untrained networks replay the identical public observations. Scaling is fitted on training episodes only. Ridge uses the original six regularization candidates and validation-only selection.

The new comparator is a **72→64→64→6 tanh MLP** consuming exactly the flattened recent eight public observations. It predicts the same six posterior targets, standardized using training target means/scales. Use Adam, learning rate .001, batch512, **40 epochs** and two weight-decay candidates **.0001 and .01**. Initialize both candidates identically using decoder seed `2026 + policy_seed`, and use the same training permutation sequence. Select weight decay and the checkpoint at epochs 5,10,…,40 by mean validation standardized MSE across all six targets. Never select on test episodes or fit scalers on validation/test data; do not refit after selection. The maximum tuning budget is two fits and 16 candidate checkpoints per policy, distinct from the ridge tuning budget.

Primary descriptive comparisons are nonlinear history versus linear history, and history-plus-trained-state ridge versus nonlinear history. Also retain the trained-versus-untrained ridge control. Report all targets, all five seeds, target variance and separate seed/whole-episode uncertainty for paired MSE differences. Intervals are exploratory and unadjusted for multiple comparisons. No winner is declared from a favorable target alone. Do not combine episode and seed intervals as if independent.

The nonlinear model is a stronger finite-capacity control, not an exhaustive test of conditional independence. If trained state still predicts better, capacity/optimization differences remain possible; that alone does not prove uniquely older information. If nonlinear history catches up, the earlier linear-probe advantage is insufficient evidence for an older-memory claim. Neither outcome establishes causal policy use. No causal intervention, architecture sweep or extra training budget is authorized by this protocol.
